# Coming soon

Применена существующая айдентика Karaoke Rave: тёплый чёрный #0B0A0A, красный #E5141B, белый #F4F1EC. Выбран логотип «Доработка старого лого» из PDF «Лого_Karaoke-Rave_доработка.pdf», страница 2: белый KARAOKE, красный RAVE, подпись «Караоке с оркестром». Оригинальный SVG-логотип сохранён без изменения геометрии; удалены только невизуальные метаданные.

Один экран, логотип — главный элемент, надпись «Скоро здесь появится сайт» ниже. Fira Sans Extra Condensed 800, открытый межстрочный интервал для кириллицы. Адаптивная ширина, поля с учётом вырезов экрана, отсутствие обязательного JavaScript и внешних запросов. Короткое появление отключается при prefers-reduced-motion.
