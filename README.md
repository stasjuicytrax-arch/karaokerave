# Караоке Рейв

Афиша ближайшего события (4 января 2027) и галерея из пяти предоставленных фотографий. Фирменный SVG-логотип из «Доработка старого лого», чёрный, красный и белый цвета, локальный Fira Sans Extra Condensed сохранены.

Статические HTML/CSS и небольшой JavaScript для просмотра изображений. Без сборки, внешних библиотек и внешних запросов. Фото в WebP с адаптивным разрешением и отложенной загрузкой; оригинальная афиша JPEG показана целиком. Источники изображений перечислены в assets/origins.json.

Просмотр: нажать на фото или афишу. Листание кнопками и стрелками клавиатуры, закрытие кнопкой или Escape. Без JavaScript ссылки открывают изображение напрямую.

Локальный просмотр: `python -m http.server 8765`.

Публикация: GitHub Pages, ветка main, папка /.
