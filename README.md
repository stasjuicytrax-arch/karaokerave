# Караоке Рейв

Одностраничная заглушка будущего сайта: оригинальный логотип и сообщение о скором запуске.

Статические HTML/CSS, без JavaScript, сборки, сторонних библиотек и внешних запросов. Шрифт Fira Sans Extra Condensed хранится локально. Логотип и цвета взяты из существующего фирменного стиля.

Для локального просмотра: `python -m http.server 4173`.

Публикация: GitHub Pages, ветка `main`, папка `/`.
