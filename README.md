# Караоке Рейв

Сайт проекта с афишей, галереей из 15 фотографий и формой для организаторов.

Статический сайт без шага сборки. Разметка находится в `index.html`, стили, локальные шрифты и модули Three.js — в `preview/`. Фотографии в WebP загружаются по мере прокрутки.

Галерея поддерживает листание кнопками, стрелками клавиатуры и свайпами. При отключённом JavaScript ссылки открывают изображения напрямую.

Локальный просмотр: `python -m http.server 8765`.

GitHub Pages публикует корень ветки `main` на [karaokerave.ru](https://karaokerave.ru/). Старый адрес `/preview/` перенаправляет на главную с сохранением ссылки на раздел и параметров URL при включённом JavaScript.
